# Public Screenshots

This directory is reserved for screenshots used in the public JuDoctor README and release presentation.

Expected V1 screenshots:

- `dashboard.png`
- `why-was-my-pc-slow.png`
- `system-capacity.png`

Before committing a screenshot:

- capture only the JuDoctor window where possible;
- remove usernames, absolute local paths, private logs, tokens, personal documents, and unrelated desktop content;
- use real but non-sensitive monitoring data;
- prefer a clean Windows capture at a readable scale;
- do not fabricate incidents or recommendations that the product did not actually produce.

The README should reference these files only after the corresponding screenshot has been reviewed and committed.
