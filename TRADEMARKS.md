# JuDoctor Name and Branding

The source code license and the project name/branding are separate matters.

The GPL-3.0 license grants rights to use, study, modify, and redistribute the covered source code under its terms. It does **not** automatically grant permission to present a modified build as the official JuDoctor product or to imply endorsement by the original project.

## You may

- accurately state that your work is based on or derived from JuDoctor
- link back to the original repository
- use the project name when referring factually to the upstream project

## You should not

- call an unofficial modified distribution the official JuDoctor release
- use JuDoctor branding in a way that suggests endorsement or authorship by the upstream maintainer
- reuse official release assets/logos as your own product identity without permission

Forks should use a clearly distinguishable product name for end-user distribution unless permission is granted.

This document is a project branding policy, not legal advice or a registered-trademark statement.
